# Code of conduct

Be decent. Assume the other person is trying to build something.

Specifically: no harassment, no personal attacks, no demands on a volunteer's
time. Technical disagreement is welcome and is not the same thing as being
unpleasant about it.

If someone is making this project worse to participate in, report it privately
through GitHub's [private reporting](https://github.com/starkshtlm/kindle-scribe-mcp/security/advisories/new)
or by opening an issue saying only that you want a private channel — do not put
the details in public. The maintainer will edit, delete or block as needed, and
will explain the decision to whoever reported it.

This applies in issues, pull requests, discussions and anywhere the project is
represented.
