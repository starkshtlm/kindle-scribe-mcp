## The recording comes first

One 20-second screen capture will do more than every word in this directory.
Nobody believes the layout part until they watch a strike-through become a
deletion.

**Storyboard**

1. Ask for a memo — a strategy or board memo, not a generic draft. Show the
   request and the reply.
2. The document appearing on the Scribe. Hold long enough to read the heading.
3. Cross out a weak assumption with the pen.
4. Write in the margin: *"too operational — frame this for the board."*
5. Draw an arrow to where the replacement belongs.
6. Share → Send by email. One tap, and it is the only manual step in the loop.
7. Ask the assistant to read the feedback.
8. Its reply, naming the decisions: the assumption removed, the framing
   changed, the section shortened.

Shoot the device with a phone or a fixed camera rather than describing it —
the pen on e-ink is half the appeal, and it does not survive a screenshot.

**Publishing.** Keep a compact GIF or an image sequence in the repository and
put the full-resolution video on a GitHub Release, so the clone stays small.
Do not add a link to the README until the asset exists.
